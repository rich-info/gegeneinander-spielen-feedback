
# Gegeneinander spielen
Kostenlose Spiele direkt im Browser. Ohne Anmeldung. Keine Werbung.

🌐 **[gegeneinander-spielen.de](https://www.gegeneinander-spielen.de)**

Einfach Spiel auswählen und losspielen.

## 🎮 Spiele

Auf **Gegeneinander spielen** findest du einfache und unterhaltsame Spiele, die du direkt im Browser spielen kannst.

Ideal für Freunde, Familie, Paare oder einfach für eine schnelle Runde zwischendurch.

## ✨ Ohne Werbung und Anmeldung

Die Spiele sind:

* 🆓 kostenlos
* 🚫 ohne Werbung
* 🔓 ohne Anmeldung
* 🌐 direkt im Browser spielbar
* 📱 auch für mobile Geräte geeignet

## 💡 Wünsche und Spielideen

Du hast eine Idee für ein neues Spiel?

Oder dir fehlt eine Funktion?

Dann erstelle gerne ein **GitHub Issue** und schlage dein Wunschspiel oder eine Verbesserung vor.

👉 [Spiel vorschlagen](https://github.com/rich-info/gegeneinander-spielen-feedback/issues/new)

Auch Feedback und Verbesserungsvorschläge sind willkommen.

## 🐛 Fehler gefunden?

Wenn etwas nicht funktioniert, kannst du ebenfalls ein GitHub Issue erstellen.

Beschreibe möglichst kurz:

* Welches Spiel betroffen ist
* Was passiert ist
* Auf welchem Gerät bzw. Browser du gespielt hast
